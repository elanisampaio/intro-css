Introdução ao CSS

O que é CSS?

CSS significa Cascading Style Sheets, ou, em português, Folhas de Estilo em Cascatas.

É a linguagem responsavél por definir a apresentação visual de um documento HTML.

Como trabalhar com o CSS?

Existe três formas clássicas de colocar o CSS em um arquivo HTML:

  • css inline
  • css interno
  • css externo

Conhecendo o CSS inline

Nessa abordagem o CSS é colocado diretamente no elemento HTML através de um atributo chamado de style
